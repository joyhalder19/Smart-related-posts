## Wordpress Plugin: Smart Related Posts

### Plugin Description

Smart Related Posts is a WordPress plugin that helps visitors discover relevant content and explore more of a website. Developed for Task 4, it identifies related posts through shared categories and tags and displays recommendations wherever the [related_posts] shortcode is placed.

The plugin provides a dedicated administration page where website administrators can configure matching criteria, select eligible post types, choose the number of recommendations, and adjust excerpt length. Each recommendation can include a title, featured image, short description, and link to the full article.

Responsive grid and list layouts make the recommendations readable on desktop and mobile devices. Administrators can customize card background colors, corner rounding, and the keyboard focus accent color to suit their website.

Relevance ordering prioritizes stronger category and tag matches, while optional randomization adds variety using only matching content. The plugin excludes the current post, unpublished content, and password-protected posts. When no related content is available, it leaves the recommendation section hidden.

Smart Related Posts also supports public custom post types that use WordPress categories or tags. Built with WordPress APIs and a straightforward configuration interface, it offers a practical, lightweight solution for improving content navigation without requiring visitors or administrators to learn a complicated new workflow

### Installation & Usage Instructions

1. In WordPress, go to Plugins → Add New Plugin → Upload Plugin.
2. Select smart-related-posts.zip, click Install Now, then Activate Plugin.
3. Go to Settings → Smart Related Posts to choose matching categories or tags, post count, layout, and display options.
4. Edit a post and add a Shortcode block where you want recommendations to appear.
5. Enter [related_posts] and update the post.

Publish posts with shared categories or tags to provide matches. The plugin displays each matching post’s title, featured image, excerpt, and link.
